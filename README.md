# Anima 语音通话

Anima 语音通话是 Neo-MoFox 的语音交互插件。它通过本机麦克风识别讲话，让 Bot 生成回复并通过扬声器播放，也支持从平台私聊临时切换到语音交互。

## 功能

- 使用 FunASR 识别麦克风输入，支持语音活动检测、热键和持续监听。
- 使用 GPT-SoVITS 合成回复，支持流式播放和完整音频播放。
- 接通、等待、挂断及静默超时管理，结束通话后恢复原来的聊天方式。
- 播放回复期间暂停识别输入，减少 Bot 听到自己声音的情况。
- 在原聊天中保留识别文本和回复记录。

## 使用条件

- Neo-MoFox 1.2.0-alpha 或更新版本，以及 Python 3.11 或更新版本。
- 启用 `neo_default_chatter` 和 `tts_voice_plugin-neo`，并配置好对话模型与 GPT-SoVITS。
- TTS 插件须提供本插件所需的语音服务和公共语音规则模板；仅有旧版完整音频接口的版本不能使用。
- Bot 所在电脑有可用的麦克风、扬声器或耳机，并已安装 FunASR 及相应音频依赖。

默认启用流式语音，需要支持 V5 PCM 流的 GPT-SoVITS 服务。使用其他兼容的完整音频服务时，可在配置中关闭 `tts.streaming_enabled`。

## 安装与配置

在 Neo-MoFox 项目根目录执行：

```bash
git clone https://github.com/tt-P607/anima_voice.git plugins/anima_voice
```

首次加载后，配置位于 `config/plugins/anima_voice/config.toml`。主要设置如下：

| 设置 | 用途 |
| --- | --- |
| `plugin` | 对话模型、附加提示词与插件开关 |
| `audio` | 麦克风和输出设备 |
| `asr` | 识别模型、推理设备及是否常驻监听 |
| `activation` | 监听方式和热键 |
| `tts` | 流式或完整音频播放 |
| `voice_call` | 静默自动挂断时间 |

`asr.enabled` 默认关闭。需要常驻麦克风交互时将其开启；关闭时，平台私聊接通仍可临时启动麦克风。语音模型、音色和合成服务地址在 TTS 插件中配置。

更详细的配置与旧配置迁移方法见 [配置说明](docs/configuration.md)。

## 通话与命令

平台私聊中，Bot 可调用接通和挂断动作。接通后，麦克风识别内容继续进入该私聊，回复通过本机音频设备播放。

| 命令 | 用途 |
| --- | --- |
| `/voice status` | 查看当前通话状态 |
| `/voice off` | 手动挂断当前聊天的通话 |

这两个命令需要 Bot 所有者权限。

## 注意事项

- 平台私聊接管不是平台原生语音呼叫：声音从运行 Bot 的电脑采集和播放，不会自动连接对方手机的麦克风与扬声器。
- 同时只能进行一通平台接管通话；通话状态不在 Bot 重启后恢复。
- 语音识别质量和回复等待时间取决于模型、硬件与收音环境。使用耳机可减少回声。
- 安装其他麦克风监听插件时，应避免同时监听同一设备。
- 识别文本和语音回复会进入聊天历史，使用前应告知参与者。
